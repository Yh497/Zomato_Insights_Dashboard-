# Zomato Insights Dashboard 📊

An interactive Power BI dashboard analyzing Zomato's restaurant data to provide actionable business insights regarding delivery performance, customer ratings, and cuisine trends.

## 🚀 Project Overview
This project transforms raw Zomato data into a visual story. It helps stakeholders understand market penetration, price-to-rating correlations, and regional performance.

## 🛠️ Tools Used
- **Power BI Desktop**: Data modeling, DAX measures, and Visualization.
- **Power Query**: Data cleaning and ETL (Extract, Transform, Load).
- **Python**: (Optional) For advanced data preprocessing.

## 📈 Key Insights
- **Rating Analysis**: Identification of the correlation between price range and average customer rating.
- **Geographic Distribution**: Mapping restaurant density across different cities/localities.
- **Service Types**: Comparison between 'Delivery' vs. 'Dine-in' popularity.
- **Cuisine Trends**: Top-performing cuisines based on order volume and sentiment.

## 📂 Repository Structure
- `Zomato_Insights_Dashboard.pbix`: The main Power BI report file.
- `/data`: Folder containing the datasets used (CSV/Excel).
- `/screenshots`: Images of the dashboard pages.

## 📖 How to View
1. Download the `Zomato_Insights_Dashboard.pbix` file.
2. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the file to interact with the filters and charts.
